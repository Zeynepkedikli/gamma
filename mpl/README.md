Programs Overview

Number and Math Programs

average_number.py – Calculates the average of numbers using lists, sum(), and len().
belowten.py – Checks or lists numbers below ten using conditions.
bigest_three.py – Finds the largest of three numbers using comparisons.
biggest_numbers.py – Finds the maximum value in a list using max().
factorial.py – Calculates factorial using a loop.
factor_test.py – Checks if a number is a factor of another using %.
power_numbers.py – Calculates power of numbers using **.
primenumber.py – Checks if a number is prime using loop and modulus.

Random and Probability Programs

dices_simualiton.py – Simulates dice rolls using random.randint().

probability.py – Performs basic probability calculations.

random_list_1.py – Creates a list of random numbers.

randoml_list_2.py – Another random list example.

randomnumbers (1).py – Generates random numbers.

Geometry Programs

triangle_check.py – Checks triangle validity using side length rules.

triangle_test.py – Tests triangle conditions with logical operators.

String and Loop Examples

reversed_text.py – Reverses a text string using slicing.

range.py – Demonstrates usage of the range() function.
